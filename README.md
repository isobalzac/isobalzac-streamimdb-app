# StreamIMDB Android / Android TV Uygulaması

streamimdb.ru için Android telefon ve Android TV uygulaması.

## Özellikler
- 📱 Android 5.0+ telefon desteği
- 📺 Android TV / Fire TV / Mi Box desteği
- 🎮 Uzaktan kumanda navigasyonu
- ▶️ Tam ekran video oynatma
- ⏩ Medya tuşları (10sn ileri/geri)
- 🎯 D-Pad navigasyonu

## APK İndirme

Sağ taraftaki **Releases** bölümünden en son APK'yı indir.

## Kurulum

1. APK dosyasını indir
2. **Telefon**: Ayarlar → Güvenlik → Bilinmeyen kaynaklar ✅
3. **Android TV**: Ayarlar → Güvenlik → Bilinmeyen kaynaklar ✅  
   (veya Downloader uygulaması ile kur)
4. APK'yı aç ve kur

## Geliştirme

Bu repo'yu fork edip GitHub Actions otomatik APK üretir.
